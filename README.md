Proyecto CodeNBuses — Gestión de Buses de Transporte Extraurbano

Proyecto 1 del curso Introducción a la Programación y Computación 2 (IPC2) Segundo Semestre 2026 — Centro Universitario de Occidente, USAC

Descripción

Aplicación web para la empresa "Code 'n Bugs" que permite a una empresa de transporte extraurbano en Guatemala gestionar su flota de buses, rutas, viajes (regulares y de alquiler privado), choferes, ventas de boletos, gastos operativos y reportes financieros por sucursal.

Tecnologías
Lenguaje: Java
Servidor web: Apache Tomcat 10.1.59
Framework de presentación: JSP (Jakarta EE 10)
Base de datos: MySQL
Gestor de dependencias: Maven
Control de versiones: Git

Configuración local
Ejecutar el script SQL para crear la base de datos gestion_buses.
Configurar usuario y contraseña de MySQL en persistencia/ConexionBase.java.
Verificar que Apache Tomcat 10 esté registrado en el IDE.
Ejecutar el proyecto y acceder mediante http://localhost:8080/ProyectoCodeNBuses/.
